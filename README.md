# 📡 MikroTik-Style Captive Portal & WiFi Hotspot Management System

> **টার্মাক্স (Termux - Android)-এর জন্য সম্পূর্ণ বাংলায় সহজ ও প্রফেশনাল ক্যাপটিভ পোর্টাল ও ওয়াইফাই হটস্পট ম্যানেজমেন্ট সিস্টেম।**  
> ফ্রেমওয়ার্ক: **Flask (Python)** | ডাটাবেস: **SQLite3** | আর্কিটেকচার: **Single-File (`app.py`)**

---

## 🌟 এই সিস্টেমের মূল ফিচারসমূহ

1. 📶 **স্বয়ংক্রিয় ক্যাপটিভ পোর্টাল পপআপ (Sign in to network):**  
   হটস্পটে কানেক্ট হওয়ামাত্রই ইউজারের মোবাইল স্ক্রিনে স্বয়ংক্রিয়ভাবে লগইন পপআপ ওপেন হবে।
2. 📦 **প্যাকেজ প্ল্যান সিস্টেম:**  
   ১ টাকা, ২ টাকা, ৫ টাকা বা আপনার ইচ্ছামতো সময় (মিনিট/ঘণ্টা) নির্ধারণ করে প্যাকেজ সাজাতে পারবেন।
3. 💳 **বিকাশ ও নগদ পেমেন্ট গেটওয়ে (অটো ও ম্যানুয়াল):**  
   ইউজার প্যাকেজ সিলেক্ট করে বিকাশ/নগদ নম্বরে টাকা পাঠিয়ে Transaction ID সাবমিট করতে পারবে।
4. 🎟️ **৪-ডিজিট ভাউচার পিন:**  
   পেমেন্ট অ্যাপ্রুভ হওয়ামাত্রই ইউজার একটি ৪-সংখ্যার সিকিউর ভাউচার কোড পাবে যা দিয়ে ইন্টারনেট চালু হবে।
5. ⏱️ **রিয়েলটাইম এক্সপায়ারি টাইমার:**  
   ইন্টারনেট চালু হওয়ার পর ইউজারের স্ক্রিনে সময় কাউন্টডাউন চলবে। সময় শেষ হলে স্বয়ংক্রিয়ভাবে ইন্টারনেট ডিসকানেক্ট হয়ে যাবে।
6. 📊 **শক্তিশালী অ্যাডমিন ড্যাশবোর্ড:**  
   লাইভ সেশন মনিটর, পেন্ডিং অর্ডার অনুমোদন/প্রত্যাখ্যান, ম্যানুয়াল ভাউচার তৈরি ও ইউজার কিক করার সুবিধা।
7. 🎨 **সম্পূর্ণ সাইট কাস্টমাইজেশন:**  
   অ্যাডমিন প্যানেল থেকেই পোর্টালের নাম, লোগো, শিরোনাম, বাটন ও থিমের রঙ পরিবর্তন করা যায়।
8. 💬 **ইউজার-অ্যাডমিন মেসেজিং:**  
   ইউজার কোনো সমস্যায় পড়লে সরাসরি পোর্টাল থেকেই অ্যাডমিনকে মেসেজ পাঠাতে পারবে এবং অ্যাডমিন উত্তর দিতে পারবে।

## 🟢 সার্ভার চালু করার নিয়ম

আপনার ফোনের **Portable Hotspot (ওয়াইফাই হটস্পট)** অন করুন (হটস্পটে কোনো পাসওয়ার্ড রাখবেন না বা ওপেন রাখবেন)।

এরপর টার্মাক্সে নিচের যে কোনো একটি পদ্ধতিতে চালু করুন:

### 🌟 পদ্ধতি ১ (সেরা পদ্ধতি - স্বয়ংক্রিয় পপআপ ও রিডাইরেকশন):
```bash
bash portal_engine.sh
```
> **এই স্ক্রিপ্টটির সুবিধা:**  
> - এটি ফোনের হটস্পট আইপি (যেমন: `192.168.9.8` বা `192.168.43.1`) নিজে থেকেই খুঁজে নেয়।  
> - এটি রুট পারমিশন নিয়ে `iptables` ও `dnsmasq` চালু করে, ফলে ক্লায়েন্ট কানেক্ট হওয়ামাত্রই **"Sign in to network"** নোটিফিকেশন পপআপ হয়ে যাবে।

---

### 🔹 পদ্ধতি ২ (সাধারণ টেস্ট মোড - রুট ছাড়া):
```bash
python app.py
```
*(এই মোডে ব্রাউজার থেকে সরাসরি আপনার আইপিতে যেমন `http://192.168.9.8:8080` গিয়ে টেস্ট করতে হবে।)*

## 📱 ইউজার যেভাবে ইন্টারনেট ব্যবহার করবে (User Flow)

```text
১. ইউজার আপনার হটস্পটে (WiFi) কানেক্ট করবে।
                     ↓
২. স্ক্রিনে সাথে সাথে "Sign in to network" পপআপ ভেসে উঠবে।
                     ↓
৩. ইউজার ১ টাকা / ২ টাকা / ৫ টাকার যে কোনো প্যাকেজ বেছে নিবে।
                     ↓
৪. প্রদর্শিত বিকাশ বা নগদ নম্বরে টাকা পাঠিয়ে Transaction ID ইনপুট দিবে।
                     ↓
৫. অ্যাডমিন ড্যাশবোর্ড থেকে অনুমোদন (Approve) করলেই ইউজার ৪-ডিজিট কোড পাবে।
                     ↓
৬. "Connect" বাটনে চাপ দিলেই ইন্টারনেট চালু হয়ে যাবে এবং কাউন্টডাউন শুরু হবে!
```

## 🛠️ সাধারণ সমস্যার সমাধান (Troubleshooting)

### ১. কোড আপডেট করতে চাইলে (নতুন ভার্সন নামানো):
```bash
cd ~/MikroTik-Style-Captive-Portal-WiFi-Hotspot-Management-System
git pull origin main
```

### ২. ডাটাবেস রিসেট বা পরিষ্কার করতে চাইলে:
```bash
rm -f hotspot.db
python app.py
```

### ৩. "Internal Server Error" দেখালে করণীয়:
সিস্টেমে অটো-হিলিং যুক্ত করা আছে। পেজটি একবার রিফ্রেশ করুন অথবা `rm -f hotspot.db` দিয়ে সার্ভার পুনরায় চালু করুন।

### ৪. পপআপ না আসলে কী করবেন?
নিশ্চিত করুন আপনি `bash portal_engine.sh` দিয়ে স্ক্রিপ্টটি চালু করেছেন এবং আপনার ফোনটি রুটেড (Rooted) ও Magisk/KernelSU দিয়ে টার্মাক্সকে Superuser পারমিশন দেওয়া আছে।
