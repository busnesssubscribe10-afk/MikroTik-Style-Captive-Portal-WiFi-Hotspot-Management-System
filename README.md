# 📡 MikroTik-Style Captive Portal & WiFi Hotspot Management System

> **টার্মাক্স (Termux - Android) এবং পিসির জন্য সম্পূর্ণ বাংলায় প্রফেশনাল ক্যাপটিভ পোর্টাল ও ওয়াইফাই হটস্পট ম্যানেজমেন্ট সিস্টেম।**  
> ফ্রেমওয়ার্ক: **Flask (Python)** | ডাটাবেস: **SQLite3** | আর্কিটেকচার: **Single-File (`app.py`)**

---

## 🌟 এই সিস্টেমের মূল ফিচারসমূহ

1. 📶 **MikroTik-স্টাইল ক্যাপটিভ পোর্টাল লগইন:**  
   হটস্পটে কানেক্ট হওয়ামাত্রই ইউজারের মোবাইল স্ক্রিনে সরাসরি ৪-ডিজিট ভাউচার পিন ইনপুট বক্স ও প্যাকেজ পেজ ভেসে উঠবে।
2. 🎟️ **৪-ডিজিট ভাউচার পিন দিয়ে সরাসরি কানেক্ট:**  
   ইউজার সঠিক ৪-ডিজিট পিন দিয়ে এক ক্লিকেই ইন্টারনেট সংযোগ সক্রিয় করতে পারবে।
3. 📦 **প্যাকেজ প্ল্যান সিস্টেম:**  
   ১ টাকা, ২ টাকা, ৫ টাকা বা আপনার ইচ্ছামতো সময় (মিনিট/ঘণ্টা) নির্ধারণ করে প্যাকেজ সাজাতে পারবেন।
4. 💳 **বিকাশ ও নগদ পেমেন্ট গেটওয়ে (অটো ও ম্যানুয়াল):**  
   ইউজার বিকাশ/নগদে টাকা পাঠিয়ে Transaction ID দিলেই স্বয়ংক্রিয়ভাবে ৪-ডিজিট ভাউচার পিন পেয়ে যাবে।
5. ⏱️ **রিয়েলটাইম এক্সপায়ারি টাইমার:**  
   ইন্টারনেট চালু হওয়ার পর স্ক্রিনে সময় কাউন্টডাউন চলবে। প্যাকেজের নির্ধারিত সময় শেষ হওয়ামাত্রই ইন্টারনেট বন্ধ হয়ে যাবে এবং পুনরায় পোর্টাল পেজে নিয়ে যাবে।
6. 📊 **শক্তিশালী অ্যাডমিন ড্যাশবোর্ড:**  
   লাইভ সেশন মনিটর, পেন্ডিং অর্ডার অনুমোদন, ম্যানুয়াল ভাউচার তৈরি ও ইউজার কিক করার সুবিধা।
7. 🎨 **সম্পূর্ণ সাইট কাস্টমাইজেশন:**  
   অ্যাডমিন প্যানেল থেকেই পোর্টালের নাম, লোগো, শিরোনাম, বাটন ও থিমের রঙ পরিবর্তন করা যায়।
8. 💬 **ইউজার-অ্যাডমিন মেসেজিং:**  
   ইউজার কোনো সমস্যায় পড়লে সরাসরি পোর্টাল থেকেই অ্যাডমিনকে মেসেজ পাঠাতে পারবে।

## 📁 প্রজেক্ট স্ট্রাকচার

```text
MikroTik-Style-Captive-Portal/
├── app.py              ← সম্পূর্ণ সিস্টেমের মূল পাইথন কোড (সার্ভার + ডাটাবেস + ব্যাকগ্রাউন্ড টাইমার)
├── portal_engine.sh    ← স্মার্ট ইঞ্জিন কন্ট্রোলার (Root ও Non-Root উভয় ডিভাইসেই চলে)

└── README.md           ← এই বিস্তারিত গাইড
```

নতুন ফোনে একদম শুরু থেকে চালু করতে নিচের ধাপগুলো **একটি একটি করে** রান করুন:


### ধাপ ৩: গিটহাব থেকে প্রজেক্টটি নামান (Clone)


---

### ধাপ ৪: প্রজেক্ট ফোল্ডারে প্রবেশ করুন

## 🟢 সার্ভার চালু করার নিয়ম

আপনার ফোনের **Portable Hotspot (ওয়াইফাই হটস্পট)** অন করুন (হটস্পটে কোনো পাসওয়ার্ড রাখবেন না বা ওপেন রাখবেন)।

এরপর টার্মাক্সে নিচের কমান্ডটি দিয়ে চালু করুন:

```bash
bash portal_engine.sh
```

*(অথবা সরাসরি `python app.py` লিখেও চালাতে পারেন।)*

## 💻 পিসিতে (Windows/Linux) টেস্ট করার নিয়ম

১. পিসির Mobile Hotspot চালু করুন।  
২. টার্মিনাল বা CMD ওপেন করে প্রজেক্ট ফোল্ডারে যান এবং রান করুন:
```bash
python app.py
```
৩. ব্রাউজারে প্রবেশ করুন:
* **ইউজার পোর্টাল:** `http://localhost:8080/`
* **অ্যাডমিন প্যানেল:** `http://localhost:8080/admin` *(User: `admin` | Pass: `admin`)*

## 🗑️ (ঐচ্ছিক) পুরনো ফাইল বা ফোল্ডার মুছে ফেলার কমান্ডসমূহ

> 💡 **নোট:** আপনি যদি কখনো প্রজেক্টটি নতুন করে ইনস্টল করতে চান বা পুরনো ডেটা ক্লিয়ার করতে চান, তবে নিচের কমান্ডগুলো ব্যবহার করতে পারেন:

### ১. সম্পূর্ণ প্রজেক্ট ফোল্ডার মুছে ফেলতে:
```bash
rm -rf ~/MikroTik-Style-Captive-Portal-WiFi-Hotspot-Management-System
```

```bash
rm -f ~/MikroTik-Style-Captive-Portal-WiFi-Hotspot-Management-System/hotspot.db
```

### ৩. টার্মাক্সে ব্যাকগ্রাউন্ডে চলা প্রসেস বন্ধ করতে:
```bash

```

## 📱 ইউজার যেভাবে ইন্টারনেট ব্যবহার করবে (Workflow)

```text
১. ইউজার আপনার ওপেন ওয়াইফাই হটস্পটে কানেক্ট করবে।
                     ↓
২. স্ক্রিনে বা নোটিফিকেশনে "Sign in to network" অপশন আসবে (বা ব্রাউজারে পোর্টাল ওপেন হবে)।
                     ↓
৩. ইউজার সরাসরি ৪-ডিজিট ভাউচার পিন দিতে পারবে অথবা বিকাশ/নগদ দিয়ে ১/২/৫ টাকার প্যাকেজ কিনতে পারবে।
                     ↓
৪. পেমেন্ট সাবমিট হওয়ামাত্রই ইউজার স্ক্রিনে ৪-ডিজিট ভাউচার পিন পাবে।
                     ↓
৫. পিন দিয়ে Connect চাপামাত্রই MikroTik-এর মতো ইন্টারনেট আনলক হবে এবং লাইভ টাইমার চলবে।
                     ↓
৬. নির্ধারিত সময় শেষ হওয়ামাত্রই ইন্টারনেট বন্ধ হয়ে যাবে এবং পুনরায় পিন পেজে নিয়ে যাবে।
```
